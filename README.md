# اسمع وافهم — Deutsch hören B1 / B2 🎧
### تطبيق تفاعلي لتدريب مهارة السماع باللغة الألمانية مع حفظ التقدم ومراجعة الأخطاء

تطبيق ويب خفيف يعمل محلياً بالكامل **بدون الحاجة إلى اتصال بالإنترنت** أو تثبيت أي خوادم (Offline-first Web App). يتيح تدريب مهارة الاستماع لمستويي **B1** و **B2** بشكل تفاعلي مع تصحيح تلقائي، ومراجعة للأخطاء، ونظام متكامل لتتبع الإنجاز وحفظ التقدم.

---

## 🌟 المميزات الرئيسية

- 🎧 **مكتبة شاملة (48 درساً)**:
  - **27 درساً لمستوى B1** (مقسمة حسب أبواب كتاب *Deutsch üben — Hören & Sprechen B1*).
  - **21 درساً لمستوى B2** (مقسمة حسب أبواب كتاب *Deutsch üben — Hören & Sprechen B2*).
- ⚡ **يعمل محلياً 100% دون إنترنت**:
  - لا يحتاج خادم محلي، لا Node.js، ولا بايثون. افتح `index.html` في أي متصفح وابدأ فوراً.
- 🎛️ **مشغل صوت متقدم**:
  - التحكم في سرعة الصوت (0.75×، 1×، 1.25×، 1.5×).
  - إعادة المقطع من البداية، أو التقديم/الترجيع 10 ثوانٍ.
- ✅ **تصحيح تلقائي وتقييم ذكي**:
  - أسئلة الاختيار من متعدد والصح والخطأ وتمارين أكمل الفراغات تُصحح تلقائياً فوراً مع إظهار الإجابة الصحيحة.
  - الأسئلة المقالية والمفتوحة توفر نموذج إجابة الكتاب مع إمكانية التقييم الذاتي لكل سؤال.
- 🔁 **خاصية مراجعة الأخطاء فقط (Smart Retries)**:
  - إمكانية إعادة حل الأسئلة التي أخطأت فيها فقط دون الحاجة لإعادة حل الدرس بالكامل.
  - خروج تلقائي لأي سؤال يتم حله بشكل صحيح في المحاولات اللاحقة.
- 💾 **حفظ التقدم التلقائي مع النسخ الاحتياطي**:
  - حفظ إجاباتك ونتائجك تلقائياً على المتصفح عبر `localStorage`.
  - زر **«حفظ نسخة من تقدمي»** لتصدير ملف JSON احتياطي.
  - زر **«استعادة التقدم»** لنقل تقدمك لأي جهاز أو متصفح آخر بسهولة.
- 🔍 **بحث وتصفية سريعة**:
  - تصفية بين مستويي B1 و B2، وتصفح الدروس الحالية والمنتهية، وبحث فوري باسم الدرس أو الموضوع.
- 🖼️ **دعم الوسائط والرسومات التوضيحية**:
  - نافذة تكبير عالية الدقة للخرائط والرسومات والصور التوضيحية المصاحبة للتمارين.

## 🚀 طريقة التشغيل

1. قم بتنزيل المستودع (Clone أو Download ZIP).
2. افتح ملف `index.html` مباشرة عبر أي متصفح حديث (Google Chrome, Microsoft Edge, Mozilla Firefox, Safari).
3. استمتع بالتدريب!

```bash
git clone https://github.com/abdoabdo22334456-prog/Deutsch-Hoeren.git
cd Deutsch-Hoeren
# افتح index.html مباشرة
```
